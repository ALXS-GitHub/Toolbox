# Setup

Cette section parle de la façon dont les choses s'assemblent, plutôt que des outils un par un. Chaque page est un guide : de quoi une partie de mon environnement est faite, comment les pièces communiquent entre elles, et comment je la remonte sur une nouvelle machine.

La plus grosse partie est le **harness Claude Code** : les réglages, skills, garde-fous et petits outils qui font de Claude Code mon assistant de tous les jours. À côté, on trouve l'environnement terminal sous Windows, Git et GitHub, les éditeurs, et les savoir-faire communs à plusieurs de mes projets.
