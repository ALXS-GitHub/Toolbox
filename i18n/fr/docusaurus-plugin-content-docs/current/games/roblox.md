# Roblox

Roblox est moins un jeu qu'une plateforme : des millions de jeux, tous créés par la communauté avec Roblox Studio et le
langage [Luau](/tools/dev/languages/luau). J'y joue, mais j'y développe surtout mon propre jeu,
**[Pack a K-Pop Idol](/projects/pack-a-kpop-idol)**.

Côté création, je n'écris pas le code dans Studio : il vit dans un dépôt git, je l'écris dans
[VS Code](/tools/dev/editors/vscode) avec [Claude Code](/tools/ai/coding/claude-code), et Rojo le synchronise dans
Studio. Toute la chaîne est décrite dans [Développer sur Roblox](/setup/roblox).
