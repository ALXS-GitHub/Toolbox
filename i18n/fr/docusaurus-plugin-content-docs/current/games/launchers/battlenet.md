# Battle.net

Battle.net est le lanceur obligatoire des jeux Blizzard et Activision (Overwatch, Diablo, World of Warcraft, Call of
Duty). Il n'est plus installé sur ma machine actuelle : je le réinstalle quand je reviens à l'un de ces jeux.
