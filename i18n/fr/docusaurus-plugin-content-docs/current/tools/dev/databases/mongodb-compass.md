# MongoDB Compass

Compass est l'interface graphique officielle de [MongoDB](/tools/dev/databases/mongodb) : on parcourt les collections,
on filtre les documents, on corrige une valeur à la main, on regarde la forme des données ou les performances d'une
requête.

Je l'ouvre de temps en temps, quand je veux voir les données d'un projet plutôt que de les interroger dans `mongosh`.
