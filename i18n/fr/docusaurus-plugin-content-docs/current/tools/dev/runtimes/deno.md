# Deno

Deno est un environnement d'exécution pour TypeScript créé par l'auteur de Node, pour en corriger les défauts : le
TypeScript fonctionne sans configuration, un programme n'a accès ni au réseau ni aux fichiers sans permission
explicite, et le formateur, le linter et les tests sont fournis.

Je l'utilise pour quelques projets, dont mon [portfolio](/projects/portfolio) et des projets d'apprentissage du coréen.
Pour le reste, [Bun](/tools/dev/runtimes/bun) a pris le relais.
