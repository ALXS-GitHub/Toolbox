# Tailwind CSS

Tailwind remplace les fichiers CSS par des classes utilitaires écrites directement sur les éléments :
`flex items-center gap-2 rounded-lg bg-muted px-3`. On ne cherche plus de noms de classes, le style se lit là où il
s'applique, et le CSS final ne contient que ce qui est utilisé.

C'est le style de [CortX](/projects/cortx), [Zorg](/projects/zorg), [PayLedger](/projects/payledger) et de mon
[portfolio](/projects/portfolio), avec les composants [shadcn/ui](/tools/dev/web-desktop/shadcn). C'est aussi un
format que les agents manient très bien : une demande de retouche visuelle se traduit directement en classes à changer.
