# Devicon

Devicon rassemble les logos de centaines de langages, frameworks et outils de développement, en SVG ou en police
d'icônes, prêts à intégrer dans un site ou un README.

Je l'ai beaucoup utilisé pour mon [portfolio](/projects/portfolio) et mes pages de projet, mais je n'en ai plus
l'usage en ce moment.
