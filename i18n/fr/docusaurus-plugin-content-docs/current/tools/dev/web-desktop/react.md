# React

React construit des interfaces à partir de composants : de petites fonctions qui décrivent ce qui doit s'afficher
selon l'état, et que React met à jour tout seul quand cet état change. C'est la base de toutes mes interfaces, sur le
web comme dans mes applications [Tauri](/tools/dev/web-desktop/tauri).

## Ce qui va avec

Mes projets récents partagent la même pile, ce qui me permet (et permet aux agents) de passer de l'un à l'autre sans
réapprendre :

- **[TypeScript](/tools/dev/languages/typescript)** et **[Vite](/tools/dev/web-desktop/vite)** ;
- **[Tailwind CSS](/tools/dev/web-desktop/tailwind)** et des composants **[shadcn/ui](/tools/dev/web-desktop/shadcn)** ;
- **TanStack Query** pour les données venant d'un serveur, **Zustand** pour l'état local ;
- les icônes **Lucide**, et **Motion** pour les animations.
