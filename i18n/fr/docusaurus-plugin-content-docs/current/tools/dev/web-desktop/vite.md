# Vite

Vite sert l'interface pendant le développement, avec une mise à jour instantanée à chaque enregistrement, puis
l'empaquette pour la production. Toutes mes interfaces [React](/tools/dev/web-desktop/react) passent par lui, y compris
celles de mes applications [Tauri](/tools/dev/web-desktop/tauri), qui lancent Vite en arrière-plan pendant
`cargo tauri dev`.
