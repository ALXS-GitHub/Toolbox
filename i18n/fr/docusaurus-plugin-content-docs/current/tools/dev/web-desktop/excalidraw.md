# Excalidraw

Excalidraw est un tableau blanc en ligne dont les schémas ont l'air dessinés à la main. Il est parfait pour réfléchir à
une architecture ou expliquer une idée rapidement, et existe aussi en extension VS Code.

Je ne m'en sers plus beaucoup : mes schémas sont maintenant produits par le [skill de schémas](/setup/claude-code/skills)
de Claude, qui donne directement un rendu propre et cohérent.
