# Go

Go est un langage compilé, simple et rapide à apprendre, conçu chez Google pour les serveurs et les outils en ligne de
commande : un seul binaire, une compilation éclair, la concurrence intégrée au langage.

Je l'ai appris et il reste installé, mais je ne l'utilise dans aucun projet en ce moment : pour un outil compilé, je
prends [Rust](/tools/dev/languages/rust), et pour un serveur, [TypeScript](/tools/dev/languages/typescript).
