# C++

J'utilise le C++ de temps en temps, surtout pour des défis d'algorithmique ([LeetCode, Advent of Code 2023](/projects/challenges))
et pour des simulations graphiques en OpenGL, comme mon simulateur de particules. J'ai rassemblé les petites briques
que je réutilisais d'un exercice à l'autre dans une bibliothèque publique,
[CPP-Utils](https://github.com/ALXS-GitHub/CPP-Utils).

Je compile avec **clang** (paquet `llvm` de [Scoop](/tools/dev/terminal/scoop)) et CMake, dans
[VS Code](/tools/dev/editors/vscode) avec les extensions C/C++ et CMake. Pour les projets plus ambitieux, je préfère
désormais [Rust](/tools/dev/languages/rust).
