# JavaScript

JavaScript est le langage du web, et la base de tout l'écosystème que j'utilise côté interface. Aujourd'hui, je
l'écris presque toujours sous forme de [TypeScript](/tools/dev/languages/typescript) ; le JavaScript pur reste pour les
petits scripts, les fichiers de configuration, et mes projets plus anciens comme la
[page d'accueil Chrome](/projects/chrome-homepage).
