# C

C est le langage avec lequel j'ai appris comment fonctionne vraiment un programme : la mémoire, les pointeurs, la
compilation. Je n'écris plus de projet en C, mais j'y reviens de temps en temps pour un exercice ou un défi
d'algorithmique.

Je le compile avec **clang**, installé avec le paquet `llvm` de [Scoop](/tools/dev/terminal/scoop), qui sert aussi
pour le [C++](/tools/dev/languages/cpp) et pour Treesitter dans [Neovim](/setup/neovim).
