# Raycast

Raycast est un lanceur : un raccourci clavier ouvre une barre de recherche d'où l'on lance une application, retrouve un
fichier, fait un calcul ou exécute une commande, sans toucher la souris. Longtemps réservé au Mac, il existe maintenant
sous Windows.

## Mon usage

Au-delà du lancement d'applications, ce que j'utilise le plus :

- **l'historique du presse-papiers**, pour retrouver ce que j'ai copié il y a dix minutes ;
- **le sélecteur d'emojis** ;
- **l'IA intégrée**, pour une question rapide sans ouvrir de fenêtre ;
- les **extensions**, qui ajoutent des commandes pour d'autres services.

Il complète [PowerToys](/tools/system/productivity/powertoys), dont je garde les utilitaires Windows.
