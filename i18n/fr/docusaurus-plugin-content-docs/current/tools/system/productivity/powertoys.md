# PowerToys

PowerToys est une collection d'utilitaires de Microsoft qui comblent les manques de Windows. On n'active que ceux dont
on a besoin ; voici ceux que j'utilise.

| Module | Pour |
|---|---|
| **FancyZones** | découper l'écran en zones et y ranger les fenêtres |
| **Workspaces** | rouvrir d'un coup un ensemble d'applications à leur place |
| **Always On Top** | garder une fenêtre au premier plan (`Win+Ctrl+T`) |
| **Text Extractor** | copier le texte de n'importe quelle zone de l'écran (OCR) |
| **Color Picker** | récupérer la couleur d'un pixel |
| **Peek** | prévisualiser un fichier dans l'explorateur avec `Espace` |
| **PowerRename**, **Image Resizer** | renommer ou redimensionner des fichiers en lot, au clic droit |
| **File Locksmith** | savoir quel programme bloque un fichier |
| **Advanced Paste** | coller en texte brut, en Markdown ou en JSON |
| **Environment Variables**, **Registry Preview** | modifier les variables d'environnement, lire un fichier `.reg` |

Pour lancer des applications, j'utilise [Raycast](/tools/system/productivity/raycast) plutôt que PowerToys Run.
