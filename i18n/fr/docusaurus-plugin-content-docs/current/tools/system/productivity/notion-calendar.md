# Notion Calendar

Notion Calendar est une application d'agenda qui s'appuie sur Google Agenda : mêmes événements, mais une interface plus
claire, et des raccourcis clavier pour tout faire sans souris. Il relie aussi les
événements aux pages [Notion](/tools/system/productivity/notion) qui les concernent.
