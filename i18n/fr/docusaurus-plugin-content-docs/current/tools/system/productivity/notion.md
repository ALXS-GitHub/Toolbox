# Notion

Notion mélange notes, listes et bases de données dans des pages qu'on organise librement. C'est là que vivent mes notes
personnelles et mes listes de suivi.

Il est branché sur [Claude](/tools/ai/assistants/claude) par un connecteur : je peux lui demander de retrouver une note,
de compléter une liste ou de créer une page sans ouvrir Notion. Pour le suivi de mes projets de code, en revanche,
j'utilise [Zorg](/projects/zorg), conçu pour travailler avec les agents.
