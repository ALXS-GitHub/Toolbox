# WinDirStat

WinDirStat analyse un disque et l'affiche sous forme de carte : chaque fichier est un rectangle proportionnel à sa
taille, coloré selon son type. Les gros fichiers oubliés sautent aux yeux. Je l'ouvre de temps en temps, quand un disque
se remplit ; pour un coup d'œil rapide dans le terminal, j'utilise plutôt [dust](/tools/dev/cli/small-tools).
