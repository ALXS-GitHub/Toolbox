# Outils

Voici le catalogue des outils que j'utilise. Chaque fiche part de mon usage : ce que l'outil fait dans mon setup, comment je l'ai configuré, et les astuces que je donnerais à un ami. Elle ne remplace pas la documentation officielle, vers laquelle chaque page renvoie.

Chaque fiche affiche un statut : **utilisé**, **de temps en temps** ou **en test**. Les outils que je n'utilise plus ne sont pas supprimés : ils passent dans l'[Archive](/archive), avec la raison de l'arrêt et ce qui les a remplacés.
