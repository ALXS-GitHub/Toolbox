# Zen

Zen est un navigateur basé sur Firefox, pensé pour être calme et rangé : les onglets sont dans une barre latérale
verticale, on les regroupe en **espaces de travail** (un par sujet), et l'interface s'efface pour laisser la place à la
page. C'est mon navigateur de tous les jours.

Pour le développement, j'ouvre [Chrome](/tools/web/browsers/chrome), dont ont besoin mes outils d'automatisation du
navigateur.
