# Google Chrome

Je ne navigue plus avec Chrome au quotidien — c'est le rôle de [Zen](/tools/web/browsers/zen) —, mais il reste
indispensable pour le développement : c'est le navigateur que pilotent mes agents. L'extension Claude pour Chrome et
mon skill `dev-browser` permettent à [Claude Code](/tools/ai/coding/claude-code) d'ouvrir une page, cliquer, remplir un
formulaire, lire la console ou faire une capture, pour vérifier lui-même ce qu'il vient de construire. Le détail est dans
[Le navigateur](/setup/claude-code/browser).

Ses outils de développement (inspecteur, réseau, performances) restent aussi ma référence pour déboguer une interface.
