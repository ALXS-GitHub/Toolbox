# Radmin VPN

Radmin VPN crée un réseau local virtuel entre plusieurs ordinateurs, où qu'ils soient : les jeux qui ne proposent qu'une
partie en LAN croient que tout le monde est dans la même pièce. C'est gratuit et sans configuration.

Je n'en ai pas besoin en ce moment, mais je le ressors dès qu'un jeu en réseau local revient avec des amis.
