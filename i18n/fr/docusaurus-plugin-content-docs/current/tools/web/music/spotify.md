# Spotify

Spotify est ma musique, sur tous les appareils. Je l'utilise aussi comme terrain de jeu : j'ai écrit
[Spotify Manager](/projects/spotify-manager) pour organiser ma bibliothèque mieux que l'application ne le permet. Il est
aussi branché sur [Claude](/tools/ai/assistants/claude), qui peut chercher un titre ou créer une playlist à partir d'une
description.
