# Google

Google reste mon moteur de recherche, même si une bonne partie de mes questions passe désormais par
[ChatGPT](/tools/ai/assistants/chatgpt) ou [Claude](/tools/ai/assistants/claude). Son écosystème m'accompagne aussi :
la messagerie, l'agenda (avec [Notion Calendar](/tools/system/productivity/notion-calendar)), les documents, et
[Gemini](/tools/ai/assistants/gemini).
