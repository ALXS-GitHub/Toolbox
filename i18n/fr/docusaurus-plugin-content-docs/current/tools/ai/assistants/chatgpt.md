# ChatGPT

ChatGPT est l'assistant conversationnel d'OpenAI, et l'un des deux que j'utilise tous les jours, avec
[Claude](/tools/ai/assistants/claude). Je m'en sers sur le web, dans l'application de bureau et sur le téléphone.

## Mon usage

Les deux assistants se recouvrent largement, et je passe de l'un à l'autre selon la tâche : un second avis sur une
question, une recherche sur le web, une image à générer, une conversation à la voix. Avoir deux modèles différents
sous la main est utile en soi : quand l'un bute, l'autre voit souvent le problème autrement.

L'abonnement ChatGPT donne aussi accès à [Codex](/tools/ai/coding/codex), l'agent de code d'OpenAI, que j'utilise en
ligne de commande à côté de Claude Code.

## Ce qu'il a remplacé

Au fil du temps, ChatGPT et Claude ont pris la place des autres assistants que j'avais essayés :
[Perplexity](/archive/ai/perplexity), [Grok](/archive/ai/grok) et [DeepSeek](/archive/ai/deepseek), désormais dans
l'archive.
