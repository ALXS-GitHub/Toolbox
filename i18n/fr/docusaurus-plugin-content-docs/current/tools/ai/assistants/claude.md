# Claude

Claude est l'assistant d'Anthropic, et celui autour duquel j'ai construit le plus de choses. Je l'utilise sur
claude.ai, dans l'application de bureau et sur le téléphone, et son pendant pour le code,
[Claude Code](/tools/ai/coding/claude-code), est au cœur de mon [harness](/setup/claude-code).

## Mon usage

Ce qui rend claude.ai vraiment utile chez moi, c'est ce qui y est branché :

- **Des connecteurs** vers mes services (messagerie, agenda, documents, notes, musique) : Claude peut chercher un
  e-mail, regarder mon agenda ou retrouver un document sans que je recopie quoi que ce soit.
- **Mon gestionnaire de tickets**, [Zorg](/projects/zorg/agents), par son serveur MCP : depuis le téléphone, je dicte
  une idée et Claude crée le ticket au bon endroit, pour que Claude Code le reprenne plus tard.
- **Mes skills** de production, importés depuis mon dépôt : un rapport, un schéma ou une petite doc demandés sur
  claude.ai sortent dans le même style que dans le terminal (voir
  [Les skills sur claude.ai](/setup/claude-code/claude-ai)).

Pour le reste, c'est l'usage habituel d'un assistant : réfléchir à un problème, rédiger, relire, analyser un document,
avec des projets pour garder le contexte d'un sujet d'une conversation à l'autre.
