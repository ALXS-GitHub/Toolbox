# Suno

Suno génère des chansons entières à partir d'une description : un style, une ambiance, éventuellement des paroles, et
il produit la musique, la voix et la structure (couplets, refrain). Le résultat est étonnamment abouti pour quelques
secondes d'attente.

Je m'en sers de temps en temps, pour m'amuser ou pour obtenir un morceau d'ambiance sur mesure quand j'en ai besoin
pour un projet.
