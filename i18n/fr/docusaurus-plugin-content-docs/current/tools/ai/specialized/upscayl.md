# Upscayl

Upscayl agrandit une image (×2, ×4…) en reconstruisant les détails avec un modèle d'IA, au lieu de simplement étirer
les pixels. Il tourne entièrement sur la machine, utilise la carte graphique, et propose plusieurs modèles selon le
type d'image : photo, illustration, image très compressée.

Je m'en sers pour récupérer une image trop petite — un logo, une capture, une illustration — avant de l'utiliser dans
un projet ou une page. C'est libre et gratuit, et rien n'est envoyé en ligne.
