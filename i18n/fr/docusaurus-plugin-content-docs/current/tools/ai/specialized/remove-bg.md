# remove.bg

remove.bg retire le fond d'une image automatiquement : on dépose une photo, et quelques secondes plus tard on récupère
le sujet détouré sur un fond transparent. Le résultat gratuit est en basse définition, suffisant pour une vignette ou
une maquette.

Pour un détourage en pleine résolution ou en lot, j'utilise plutôt mon script `rm_bg`, un script global de
[CortX](/projects/cortx) qui fait la même chose en local avec le modèle open source rembg.
