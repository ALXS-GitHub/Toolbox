# Audacity

Audacity est l'éditeur audio libre de référence : on voit la forme d'onde, on coupe, on ajuste le volume, on retire un
bruit de fond, on exporte dans le format voulu. Je l'ouvre de temps en temps pour retoucher un son ou un enregistrement ;
pour une simple conversion, [FFmpeg](/tools/creation/video/ffmpeg) suffit.
