# DaVinci Resolve

DaVinci Resolve est un logiciel de montage vidéo professionnel — montage, étalonnage des couleurs, effets, mixage
audio — dont la version gratuite suffit largement à un usage personnel. Je l'ouvre rarement, quand une vidéo demande un
vrai montage : plusieurs pistes, des transitions, du texte. Pour une simple coupe ou une conversion,
[FFmpeg](/tools/creation/video/ffmpeg) suffit.
