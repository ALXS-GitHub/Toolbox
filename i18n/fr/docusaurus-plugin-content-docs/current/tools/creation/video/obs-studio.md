# OBS Studio

OBS enregistre l'écran ou diffuse en direct, en composant des scènes : une fenêtre, une webcam, du texte, plusieurs
sources audio. Il est libre et gratuit. Je m'en sers rarement, pour enregistrer une démonstration ou une séquence de
jeu ; le montage se fait ensuite dans [DaVinci Resolve](/tools/creation/video/davinci-resolve).
