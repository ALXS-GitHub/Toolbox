# Blender

Blender couvre toute la chaîne de la 3D : modélisation, textures, animation, rendu, et même montage vidéo. Il est libre
et gratuit, et son niveau rivalise avec les logiciels professionnels. Je m'en sers de temps en temps pour préparer un
modèle ou un rendu, par exemple pour un jeu [Roblox](/setup/roblox).
