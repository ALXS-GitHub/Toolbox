# GIMP

GIMP est un logiciel libre de retouche d'image : calques, masques, sélections, filtres. Depuis la version 3, son
interface est nettement plus moderne. Je l'ouvre de temps en temps pour une retouche qui demande des calques — un logo à
détourer proprement, une image à composer pour un projet. Pour une génération ou une modification rapide, je passe
plutôt par [Gemini](/tools/ai/assistants/gemini), et pour agrandir une image, par [Upscayl](/tools/creation/image/upscayl).
