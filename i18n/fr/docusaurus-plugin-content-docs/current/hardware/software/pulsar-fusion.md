# Pulsar Fusion Drive

Le logiciel de Pulsar règle ma [souris Xlite V4](/hardware/accessories/mouse) : les paliers de DPI, la distance de
décollage, la fréquence d'interrogation, l'affectation des boutons et le firmware. Les réglages sont enregistrés dans la
souris, donc je ne l'ouvre que pour en changer.
