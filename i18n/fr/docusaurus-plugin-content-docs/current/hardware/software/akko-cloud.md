# Akko Cloud Driver

Le logiciel d'Akko règle mon [clavier à switchs magnétiques](/hardware/accessories/keyboard) : le point d'activation de
chaque touche, le Rapid Trigger, les touches à plusieurs actions (DKS), la réaffectation des touches, l'éclairage et le
firmware. Comme pour la souris, tout est enregistré dans le clavier.
