# Crucial Storage Executive

Mon stockage externe est un **SSD Crucial X10 Pro de 2 To**, en USB-C, pour les sauvegardes et les gros fichiers.
Crucial Storage Executive en surveille la santé (usure, température, données écrites) et installe les mises à jour de
son firmware. Il ne fonctionne qu'avec les SSD Crucial : le SSD interne, un Samsung, n'est pas concerné.
