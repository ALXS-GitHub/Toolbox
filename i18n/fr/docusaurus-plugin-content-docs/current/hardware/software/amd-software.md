# AMD Software : Adrenalin Edition

Le logiciel d'AMD installe les pilotes de la [RX 9070 XT](/hardware/computer) et règle tout ce qui touche à la carte
graphique : profils par jeu, FreeSync pour synchroniser l'image avec mes [écrans](/hardware/monitors), FSR et la
génération d'images pour gagner en fluidité, Anti-Lag pour réduire la latence, et une surcouche (`Alt+R`) qui affiche
les performances en jeu. Il prévient aussi des nouvelles versions de pilotes.
