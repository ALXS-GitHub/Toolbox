# Mes écrans

Deux écrans de 27 pouces en 1440p, côte à côte, branchés en DisplayPort sur la carte graphique.

| | Écran principal | Écran secondaire |
|---|---|---|
| **Modèle** | AOC Q27G4ZR | MSI PRO MP275QPG |
| **Dalle** | Fast IPS, 2560 × 1440 | IPS, 2560 × 1440 |
| **Fréquence** | 240 Hz | 100 Hz |
| **Pied** | réglable en hauteur, inclinaison, pivot | ergonomique |
| **Usage** | jeux compétitifs et code | documentation, terminaux, navigateur |

## Pourquoi de l'IPS plutôt que de l'OLED

Les écrans OLED ont un meilleur contraste, mais je code toute la journée sur l'écran principal : barres latérales,
terminal et interfaces fixes y restent affichés des heures, exactement ce qui use une dalle OLED (le *burn-in*). Une
dalle **Fast IPS 240 Hz** donne la fluidité qu'il faut en jeu, un texte net en développement, et aucun risque de
marquage. Le 1440p sur 27" est le bon compromis : assez de place pour deux fichiers côte à côte, et une résolution que
la [carte graphique](/hardware/computer) tient à haute fréquence.

Le second écran n'a pas besoin de vitesse : 100 Hz suffisent pour lire, et c'est là que vivent la documentation, les
journaux et le navigateur pendant que je travaille sur le premier.
