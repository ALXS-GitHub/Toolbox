# Projets

Ce sont les projets que je construis sur mon temps libre : applis de bureau, applis web, jeux et l'outillage autour. Chaque page explique ce que fait le projet, comment il est construit et où il en est.

Certains de ces projets sont privés, soit parce que leur code n'a pas vocation à être partagé, soit parce qu'ils manipulent des données personnelles. Leur page décrit comment ils fonctionnent, jamais ce qu'ils contiennent, et ne renvoie pas vers leur dépôt.
