# Comet

Comet est le navigateur de [Perplexity](/archive/ai/perplexity) : un navigateur basé sur Chromium avec un assistant
intégré, qui résume la page, répond à des questions sur ce qu'on lit et peut enchaîner des actions sur les sites.

## Pourquoi je l'ai arrêté

Je l'ai testé sans l'adopter : je reste sur [Zen](/tools/web/browsers/zen) au quotidien, et quand un agent doit
naviguer pour moi, c'est [Claude Code](/setup/claude-code/browser) qui pilote Chrome.
