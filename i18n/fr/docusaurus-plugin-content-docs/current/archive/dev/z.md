# z

z, porté en module PowerShell, retient les dossiers visités et permet d'y revenir en tapant une partie de leur nom.

## Pourquoi je l'ai arrêté

[zoxide](/tools/dev/cli/zoxide) fait la même chose en mieux : plus rapide, disponible dans tous les shells, avec une sélection interactive (`zi`). C'est [CortX](/projects/cortx) qui l'initialise.
