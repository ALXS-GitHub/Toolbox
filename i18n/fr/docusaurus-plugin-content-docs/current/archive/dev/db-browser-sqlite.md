# DB Browser for SQLite

DB Browser for SQLite ouvre un fichier SQLite pour parcourir ses tables, modifier des lignes et lancer des requêtes, sans écrire de code.

## Pourquoi je l'ai arrêté

Je n'en ai plus l'usage : mes applications SQLite, comme [PayLedger](/projects/payledger), ont leur propre CLI, que j'interroge directement ou par un agent.
