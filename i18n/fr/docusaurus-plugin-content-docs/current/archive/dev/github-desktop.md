# GitHub Desktop

GitHub Desktop rend Git visuel : on voit les fichiers modifiés et leur diff, on coche ce qu'on veut commiter, on pousse et on ouvre une pull request en quelques clics.

## Pourquoi je l'ai arrêté

Je fais maintenant mon git au clavier avec [lazygit](/tools/dev/cli/lazygit), dans le terminal, et le reste avec le CLI [`gh`](/tools/dev/version-control/github). Les agents commitent aussi eux-mêmes.
