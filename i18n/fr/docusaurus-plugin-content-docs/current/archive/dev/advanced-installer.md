# Advanced Installer

Advanced Installer construit des installeurs Windows professionnels par une interface graphique : fichiers, raccourcis, registre, prérequis, mises à jour.

## Pourquoi je l'ai arrêté

Mes applications de bureau sont en [Tauri](/tools/dev/web-desktop/tauri), qui produit lui-même les installeurs Windows et gère les mises à jour automatiques (voir [Mises à jour des apps Tauri](/setup/tauri-updates)).
