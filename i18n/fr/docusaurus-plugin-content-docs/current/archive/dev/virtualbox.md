# VirtualBox

VirtualBox crée des machines virtuelles : un autre Windows, un Linux, isolés du système principal, pour tester sans risque.

## Pourquoi je l'ai arrêté

Je n'ai plus besoin de machines virtuelles : pour un environnement Linux, [WSL](/tools/dev/terminal/wsl) suffit.
