# Neo4j

Neo4j stocke des données sous forme de graphe — des nœuds reliés par des relations — et les interroge avec le langage Cypher. C'est idéal quand les liens entre les données comptent plus que les données elles-mêmes.

## Pourquoi je l'ai arrêté

Je l'ai utilisé pour un projet qui en avait besoin ; aucun de mes projets actuels ne s'appuie sur un graphe.
