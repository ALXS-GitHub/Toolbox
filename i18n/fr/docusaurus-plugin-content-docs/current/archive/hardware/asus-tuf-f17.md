# ASUS TUF Gaming F17

Pendant plusieurs années, ce portable de 17,3 pouces a été mon seul ordinateur : développement la journée, jeu le soir.

| Pièce | Modèle |
|---|---|
| **Processeur** | Intel Core i7-11800H (8 cœurs, 16 threads) |
| **Carte graphique** | NVIDIA GeForce RTX 3060 Laptop, 6 Go |
| **Mémoire** | 16 Go DDR4-3200 |
| **Stockage** | 1 To NVMe PCIe 3.0 |
| **Écran** | 17,3" Full HD IPS, 144 Hz |

## Pourquoi je l'ai remplacé

Il arrivait à ses limites, en jeu comme pour faire tourner plusieurs projets et agents en parallèle. Je l'ai remplacé
par un [PC fixe](/hardware/computer), beaucoup plus puissant, avec deux [écrans](/hardware/monitors) 1440p.
