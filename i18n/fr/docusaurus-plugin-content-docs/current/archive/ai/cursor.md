# Cursor

Cursor est un éditeur dérivé de VS Code, construit autour de l'IA : complétion avancée, chat sur tout le projet, et un
agent capable de modifier plusieurs fichiers à la fois. Je l'ai utilisé quand ce genre d'agent n'existait que dans
l'éditeur.

## Pourquoi je l'ai arrêté

Les agents en ligne de commande l'ont remplacé : [Claude Code](/tools/ai/coding/claude-code) fait le même travail
depuis le terminal, dans n'importe quel projet, et s'étend avec mes propres outils. Je suis revenu à
[VS Code](/tools/dev/editors/vscode) comme éditeur.
