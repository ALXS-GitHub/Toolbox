# Google Stitch

Google Stitch, un outil de Google Labs, génère des maquettes d'interface web ou mobile à partir d'une description, d'un
croquis ou d'une capture d'écran, et les exporte vers Figma ou en code. C'est un bon moyen d'explorer rapidement
plusieurs directions visuelles avant d'écrire la moindre ligne.

## Pourquoi je l'ai arrêté

Je l'ai utilisé pour poser les premières maquettes de projets, mais je pars
désormais directement du code avec [Claude Code](/tools/ai/coding/claude-code), qui itère sur l'interface réelle.
