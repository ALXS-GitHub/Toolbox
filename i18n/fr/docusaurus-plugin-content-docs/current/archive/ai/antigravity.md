# Antigravity

Antigravity est l'environnement de développement de Google, pensé dès le départ pour les agents : on y lance des
agents qui planifient, codent et testent en parallèle, avec un navigateur intégré pour vérifier le résultat.

## Pourquoi je l'ai arrêté

Je l'ai installé pour l'essayer, mais il n'a pas trouvé sa place : mon environnement est construit autour de
[Claude Code](/tools/ai/coding/claude-code), qui fait déjà ce travail avec mes réglages, mes skills et mes outils.
