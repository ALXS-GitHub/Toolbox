# Setup

This section is about how things fit together rather than about individual tools. Each page is a guide: what a part of my environment is made of, how the pieces talk to each other, and how I set it up again on a new machine.

The biggest part is the **Claude Code harness**: the settings, skills, guardrails and small tools that turn Claude Code into my everyday assistant. Next to it are the Windows terminal environment, Git and GitHub, the editors, and the know-how shared by several of my projects.
