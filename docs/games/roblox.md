# Roblox

Roblox is less a game than a platform: millions of games, all made by the community with Roblox Studio and the
[Luau](/tools/dev/languages/luau) language. I play, but above all I develop my own game there,
**[Pack a K-Pop Idol](/projects/pack-a-kpop-idol)**.

On the creation side, I do not write code in Studio: it lives in a git repository, I write it in
[VS Code](/tools/dev/editors/vscode) with [Claude Code](/tools/ai/coding/claude-code), and Rojo syncs it into Studio.
The whole chain is described in [Developing on Roblox](/setup/roblox).
