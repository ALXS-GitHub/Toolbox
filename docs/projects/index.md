# Projects

These are the projects I build in my spare time: desktop apps, web apps, games and the tooling around them. Each page explains what the project does, how it is built and where it stands.

Some of these projects are private, either because their code is not meant to be shared or because they handle personal data. Their pages describe how they work, never what they contain, and do not link to their repositories.
