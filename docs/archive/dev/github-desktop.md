# GitHub Desktop

GitHub Desktop makes Git visual: you see changed files and their diff, tick what to commit, push and open a pull request in a few clicks.

## Why I stopped

I now do my git from the keyboard with [lazygit](/tools/dev/cli/lazygit), in the terminal, and the rest with the [`gh`](/tools/dev/version-control/github) CLI. Agents also commit on their own.
