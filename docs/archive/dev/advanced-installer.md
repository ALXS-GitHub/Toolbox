# Advanced Installer

Advanced Installer builds professional Windows installers through a graphical interface: files, shortcuts, registry, prerequisites, updates.

## Why I stopped

My desktop apps are on [Tauri](/tools/dev/web-desktop/tauri), which produces the Windows installers itself and handles automatic updates (see [Tauri app updates](/setup/tauri-updates)).
