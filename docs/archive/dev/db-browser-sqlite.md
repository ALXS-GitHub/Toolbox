# DB Browser for SQLite

DB Browser for SQLite opens a SQLite file to browse its tables, edit rows and run queries, without writing code.

## Why I stopped

I no longer need it: my SQLite apps, such as [PayLedger](/projects/payledger), have their own CLI, which I query directly or through an agent.
