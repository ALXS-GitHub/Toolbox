# Quarkdown

Quarkdown extends Markdown with functions, variables and layouts, to produce documents, slides or books from the same text.

## Why I stopped

I tried it for my documents, but [Typst](/tools/creation/documents/typst) covers the same need with a sturdier ecosystem.
