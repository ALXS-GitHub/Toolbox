# Google Stitch

Google Stitch, a Google Labs tool, generates web or mobile interface mock-ups from a description, a sketch or a
screenshot, and exports them to Figma or code. It is a good way to explore several visual directions quickly before
writing a single line.

## Why I stopped

I used it to lay down the first mock-ups of projects, but I now start straight from
code with [Claude Code](/tools/ai/coding/claude-code), which iterates on the real interface.
