# Antigravity

Antigravity is Google's development environment, built for agents from the start: you launch agents that plan, code
and test in parallel, with a built-in browser to check the result.

## Why I stopped

I installed it to try it, but it never found its place: my environment is built around
[Claude Code](/tools/ai/coding/claude-code), which already does that work with my settings, skills and tools.
