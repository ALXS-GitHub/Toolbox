# Cursor

Cursor is an editor forked from VS Code, built around AI: advanced completion, chat over the whole project, and an
agent able to change several files at once. I used it when that kind of agent only existed inside the editor.

## Why I stopped

Command-line agents replaced it: [Claude Code](/tools/ai/coding/claude-code) does the same work from the terminal, in
any project, and extends with my own tools. I went back to [VS Code](/tools/dev/editors/vscode) as my editor.
