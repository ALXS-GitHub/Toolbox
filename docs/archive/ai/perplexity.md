# Perplexity

Perplexity is an answer engine: you ask a question, it searches the web and writes an answer citing its sources, which
you can open to check. That was its big advantage when assistants could not search online yet.

## Why I stopped

[ChatGPT](/tools/ai/assistants/chatgpt) and [Claude](/tools/ai/assistants/claude) now search the web with their
sources; one more tool no longer brought me anything.
