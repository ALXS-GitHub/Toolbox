# GitHub Copilot

GitHub Copilot completes code as you type, in VS Code, Neovim and other editors, and offers a chat to ask questions
about the project. It was my first coding assistant, and I kept it a long time for its inline suggestions, in VS Code and Neovim.

## Why I stopped

The way I code changed: rather than being completed line by line, I describe the change to an agent that makes it in
full. [Claude Code](/tools/ai/coding/claude-code) took the whole
place.
