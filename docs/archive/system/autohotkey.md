# AutoHotkey

AutoHotkey lets you create keyboard shortcuts, expand text on the fly and automate actions on Windows with small scripts.

## Why I stopped

I no longer need it: the few shortcuts I use go through [PowerToys](/tools/system/productivity/powertoys) and [Raycast](/tools/system/productivity/raycast).
