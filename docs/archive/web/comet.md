# Comet

Comet is [Perplexity](/archive/ai/perplexity)'s browser: a Chromium-based browser with a built-in assistant that
summarises the page, answers questions about what you read and can chain actions on websites.

## Why I stopped

I tried it without adopting it: I stay on [Zen](/tools/web/browsers/zen) day to day, and when an agent has to browse
for me, [Claude Code](/setup/claude-code/browser) drives Chrome.
