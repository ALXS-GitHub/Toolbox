# Notion

Notion mixes notes, lists and databases in pages you organise freely. It is where my personal notes and tracking lists
live.

It is plugged into [Claude](/tools/ai/assistants/claude) through a connector: I can ask it to find a note, fill in a
list or create a page without opening Notion. To track my code projects, however, I use [Zorg](/projects/zorg), built to
work with agents.
