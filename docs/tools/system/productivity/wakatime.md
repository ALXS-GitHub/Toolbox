# WakaTime

WakaTime measures coding time automatically: an editor extension sends activity signals, and the dashboard turns them
into statistics per project, language and day. There is nothing to start or stop.

I use it with the [VS Code](/tools/dev/editors/vscode) extension. It is mostly a useful curiosity: seeing where my time
goes, and which projects I really come back to.
