# PowerToys

PowerToys is a collection of Microsoft utilities that fill Windows' gaps. You only turn on what you need; here is what I
use.

| Module | For |
|---|---|
| **FancyZones** | split the screen into zones and snap windows into them |
| **Workspaces** | reopen a set of apps in their places in one go |
| **Always On Top** | keep a window in front (`Win+Ctrl+T`) |
| **Text Extractor** | copy the text of any area of the screen (OCR) |
| **Color Picker** | grab a pixel's colour |
| **Peek** | preview a file in Explorer with `Space` |
| **PowerRename**, **Image Resizer** | rename or resize files in bulk, from the right-click menu |
| **File Locksmith** | find which program locks a file |
| **Advanced Paste** | paste as plain text, Markdown or JSON |
| **Environment Variables**, **Registry Preview** | edit environment variables, read a `.reg` file |

To launch apps, I use [Raycast](/tools/system/productivity/raycast) rather than PowerToys Run.
