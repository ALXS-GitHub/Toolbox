# Raycast

Raycast is a launcher: a keyboard shortcut opens a search bar from which you start an app, find a file, do a
calculation or run a command, without touching the mouse. Long a Mac exclusive, it is now available on Windows.

## How I use it

Beyond launching apps, what I use most:

- **clipboard history**, to find what I copied ten minutes ago;
- **the emoji picker**;
- **built-in AI**, for a quick question without opening a window;
- **extensions**, which add commands for other services.

It complements [PowerToys](/tools/system/productivity/powertoys), whose Windows utilities I keep.
