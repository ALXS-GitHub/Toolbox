# Wallpaper Engine

Wallpaper Engine, sold on Steam, shows animated wallpapers: videos, interactive scenes or web pages. Its workshop offers
hundreds of thousands. It pauses by itself when an app goes full screen, so it uses no resources during a game.

It replaced [Lively Wallpaper](/archive/system/lively-wallpaper).
