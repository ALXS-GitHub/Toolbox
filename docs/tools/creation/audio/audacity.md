# Audacity

Audacity is the reference free audio editor: you see the waveform, cut, adjust volume, remove background noise and
export to the format you need. I open it now and then to touch up a sound or a recording; for a plain conversion,
[FFmpeg](/tools/creation/video/ffmpeg) is enough.
