# OBS Studio

OBS records the screen or streams live, composing scenes: a window, a webcam, text, several audio sources. It is free
and open source. I use it rarely, to record a demo or a gameplay sequence; editing then happens in
[DaVinci Resolve](/tools/creation/video/davinci-resolve).
