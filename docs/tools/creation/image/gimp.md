# GIMP

GIMP is free image editing software: layers, masks, selections, filters. Since version 3, its interface is much more
modern. I open it now and then for an edit that needs layers — a logo to cut out cleanly, an image to compose for a
project. For a quick generation or edit I rather go through [Gemini](/tools/ai/assistants/gemini), and to enlarge an
image, through [Upscayl](/tools/creation/image/upscayl).
