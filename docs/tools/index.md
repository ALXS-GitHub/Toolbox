# Tools

This is the catalogue of the tools I use. Each page is written from my own use: what the tool does in my setup, how I configured it, and the tips I would give a friend. It is not a replacement for the official documentation, which every page links to.

Every page shows a status: **in use**, **now and then**, or **testing**. Tools I no longer use are not deleted: they move to the [Archive](../archive/index.md), with the reason I stopped and what replaced them.
