# Spotify

Spotify is my music, on every device. I also use it as a playground: I wrote [Spotify Manager](/projects/spotify-manager)
to organise my library better than the app allows. It is also plugged into [Claude](/tools/ai/assistants/claude), which
can find a track or create a playlist from a description.
