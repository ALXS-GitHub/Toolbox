# Zen

Zen is a Firefox-based browser designed to be calm and tidy: tabs sit in a vertical sidebar, you group them into
**workspaces** (one per topic), and the interface fades away to leave room for the page. It is my everyday browser.

For development I open [Chrome](/tools/web/browsers/chrome), which my browser automation tools need.
