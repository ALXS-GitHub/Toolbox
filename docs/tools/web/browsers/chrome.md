# Google Chrome

I no longer browse with Chrome day to day — that is [Zen](/tools/web/browsers/zen)'s job — but it remains essential for
development: it is the browser my agents drive. The Claude extension for Chrome and my `dev-browser` skill let
[Claude Code](/tools/ai/coding/claude-code) open a page, click, fill in a form, read the console or take a screenshot, to
check for itself what it just built. Details are in [The browser](/setup/claude-code/browser).

Its developer tools (inspector, network, performance) also remain my reference to debug an interface.
