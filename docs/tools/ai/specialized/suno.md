# Suno

Suno generates whole songs from a description: a style, a mood, possibly lyrics, and it produces the music, the vocals
and the structure (verses, chorus). The result is surprisingly polished for a few seconds' wait.

I use it now and then, for fun or to get a custom background track when a project needs one.
