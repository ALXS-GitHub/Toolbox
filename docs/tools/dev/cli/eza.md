# eza

eza replaces `ls` (and PowerShell's `Get-ChildItem`) with a listing you read at a glance: colours by file type, icons,
folders first, and each file's git status. It is the community-maintained successor of exa, which no longer receives
updates.

## How I use it

I never type `eza` directly: four aliases, generated by [CortX](/projects/cortx) for all my shells, stand in for it.

| Alias | Command | For |
|---|---|---|
| `ls` | `eza --icons --group-directories-first` | the basic listing |
| `ll` | … `-la` | details: permissions, sizes, dates, git status |
| `la` | … `-a` | with hidden files |
| `lt` | … `--tree --level=2` | a two-level tree |

In the long view, each file carries a git marker (new, modified, ignored): an `ll` often serves as a mini
`git status`. And `lt` gives exactly the depth needed to understand a project's layout; with `--git-ignore`, it skips
folders such as `node_modules`.

Icons need a **Nerd Font** in the terminal.

## What it replaces

The Terminal-Icons PowerShell module, which I used to get icons with `Get-ChildItem`, and the `tree` command.
