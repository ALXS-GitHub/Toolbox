# yazi

yazi is a text-mode file manager: three columns (the parent folder, the current folder, a preview), browsed from the
keyboard. It is written in Rust and everything is asynchronous: a folder of ten thousand files scrolls as fast as a
folder of ten, and image or code previews load without blocking navigation.

## How I use it

I start it with `y`, a small function generated by [CortX](/projects/cortx): when I quit yazi, the shell moves to the
last folder visited. yazi thus becomes a visual way to `cd`, rather than a separate program.

```powershell
y              # browse, then q to quit… in the folder reached
```

I use it for what is easier to see than to type: exploring an unknown folder, sorting files, renaming or deleting in
bulk, looking at an image or a PDF without opening an app. It keeps its default configuration.

With [lazygit](/tools/dev/cli/lazygit) for git and [Neovim](/setup/neovim) for editing, it completes a set of text-mode
tools that save leaving the terminal.

Image previews need a terminal that can display them; CortX's can.
