# React

React builds interfaces out of components: small functions describing what to show for a given state, which React
updates by itself when that state changes. It is the base of all my interfaces, on the web as in my
[Tauri](/tools/dev/web-desktop/tauri) apps.

## What goes with it

My recent projects share the same stack, which lets me (and agents) move from one to the next without relearning:

- **[TypeScript](/tools/dev/languages/typescript)** and **[Vite](/tools/dev/web-desktop/vite)**;
- **[Tailwind CSS](/tools/dev/web-desktop/tailwind)** and **[shadcn/ui](/tools/dev/web-desktop/shadcn)** components;
- **TanStack Query** for server data, **Zustand** for local state;
- **Lucide** icons, and **Motion** for animations.
