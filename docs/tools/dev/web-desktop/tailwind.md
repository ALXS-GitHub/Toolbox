# Tailwind CSS

Tailwind replaces CSS files with utility classes written right on the elements: `flex items-center gap-2 rounded-lg
bg-muted px-3`. No more inventing class names, the style reads where it applies, and the final CSS only contains what
is used.

It styles [CortX](/projects/cortx), [Zorg](/projects/zorg), [PayLedger](/projects/payledger) and my
[portfolio](/projects/portfolio), with [shadcn/ui](/tools/dev/web-desktop/shadcn) components. It is also a format agents
handle very well: a visual tweak request translates directly into classes to change.
