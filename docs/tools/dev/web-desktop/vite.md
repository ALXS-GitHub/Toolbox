# Vite

Vite serves the interface during development, with instant updates on every save, then bundles it for production. All
my [React](/tools/dev/web-desktop/react) interfaces go through it, including my [Tauri](/tools/dev/web-desktop/tauri)
apps', which start Vite in the background during `cargo tauri dev`.
