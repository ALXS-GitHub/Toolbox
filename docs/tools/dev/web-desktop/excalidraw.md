# Excalidraw

Excalidraw is an online whiteboard whose diagrams look hand-drawn. It is perfect to think through an architecture or
explain an idea quickly, and also exists as a VS Code extension.

I hardly use it any more: my diagrams are now produced by Claude's [diagrams skill](/setup/claude-code/skills), which
gives a clean, consistent result straight away.
