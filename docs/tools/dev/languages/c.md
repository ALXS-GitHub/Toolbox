# C

C is the language I learned how a program really works with: memory, pointers, compilation. I no longer write projects
in C, but I come back to it now and then for an exercise or an algorithm challenge.

I compile it with **clang**, installed with [Scoop](/tools/dev/terminal/scoop)'s `llvm` package, which also serves
[C++](/tools/dev/languages/cpp) and Treesitter in [Neovim](/setup/neovim).
