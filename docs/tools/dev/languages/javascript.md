# JavaScript

JavaScript is the language of the web, and the base of the whole ecosystem I use for interfaces. Today I almost always
write it as [TypeScript](/tools/dev/languages/typescript); plain JavaScript remains for small scripts, config files and
older projects such as my [Chrome homepage](/projects/chrome-homepage).
