# C++

I use C++ now and then, mostly for algorithm challenges ([LeetCode, Advent of Code 2023](/projects/challenges)) and for
graphical simulations in OpenGL, such as my particle simulator. I gathered the small building blocks I kept reusing
from one exercise to the next into a public library, [CPP-Utils](https://github.com/ALXS-GitHub/CPP-Utils).

I compile with **clang** ([Scoop](/tools/dev/terminal/scoop)'s `llvm` package) and CMake, in
[VS Code](/tools/dev/editors/vscode) with the C/C++ and CMake extensions. For more ambitious projects, I now prefer
[Rust](/tools/dev/languages/rust).
