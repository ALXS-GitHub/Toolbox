# Go

Go is a compiled language, simple and quick to learn, designed at Google for servers and command-line tools: a single
binary, lightning-fast builds, concurrency built into the language.

I learned it and it is still installed, but I do not use it in any project right now: for a compiled tool I pick
[Rust](/tools/dev/languages/rust), and for a server, [TypeScript](/tools/dev/languages/typescript).
