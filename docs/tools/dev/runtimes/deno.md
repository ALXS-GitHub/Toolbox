# Deno

Deno is a TypeScript runtime created by Node's author to fix its flaws: TypeScript works without configuration, a
program gets neither network nor file access without explicit permission, and the formatter, linter and test runner are
built in.

I use it for a few projects, including my [portfolio](/projects/portfolio) and Korean-learning projects. For the rest,
[Bun](/tools/dev/runtimes/bun) took over.
