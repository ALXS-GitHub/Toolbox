# MongoDB Compass

Compass is [MongoDB](/tools/dev/databases/mongodb)'s official graphical interface: browse collections, filter documents,
fix a value by hand, look at the data's shape or a query's performance.

I open it now and then, when I want to see a project's data rather than query it in `mongosh`.
