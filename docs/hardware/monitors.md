# My screens

Two 27-inch 1440p screens side by side, connected over DisplayPort to the graphics card.

| | Main screen | Second screen |
|---|---|---|
| **Model** | AOC Q27G4ZR | MSI PRO MP275QPG |
| **Panel** | Fast IPS, 2560 × 1440 | IPS, 2560 × 1440 |
| **Refresh rate** | 240 Hz | 100 Hz |
| **Stand** | height, tilt, pivot | ergonomic |
| **Use** | competitive games and code | docs, terminals, browser |

## Why IPS rather than OLED

OLED screens have better contrast, but I code all day on the main screen: sidebars, terminal and static interfaces stay
on screen for hours, exactly what wears out an OLED panel (*burn-in*). A **240 Hz Fast IPS** panel gives the smoothness
games need, sharp text for development, and no risk of marking. 1440p at 27" is the right balance: enough room for two
files side by side, and a resolution the [graphics card](/hardware/computer) drives at high refresh rates.

The second screen does not need speed: 100 Hz is plenty for reading, and it is where docs, logs and the browser live
while I work on the first one.
