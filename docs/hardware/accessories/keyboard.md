# Akko MOD007 V3 HE

My everyday keyboard, for coding and gaming alike. Its switches are **magnetic** (Hall effect): instead of a metal
contact, a sensor reads each key's exact position. You therefore set, key by key, how deep it actuates — very early in
games, deeper for typing without typos.

In games, **Rapid Trigger** releases the key as soon as it starts coming up, without waiting for a fixed point: changes
of direction are instant. The keyboard polls 8000 times per second, which takes it out of the latency chain.

It is also a beautiful object: a 75% layout with a knob, a machined aluminium frame with cyan tones (the "Year of the
Dragon" series) and PBT keycaps printed on five sides.

| Spec | Detail |
|---|---|
| **Layout** | 75%, with knob |
| **Switches** | Akko Cream Yellow Magnetic (Hall effect) |
| **Actuation** | adjustable from 0.1 to 3.4 mm, per key |
