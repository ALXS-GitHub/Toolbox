# Pulsar Xlite V4

My everyday mouse. It weighs only **54 g**: over a long session you tire less, and small aim corrections are faster and
more precise. Its right-handed ergonomic shape fills the hand in a palm grip and keeps the wrist straight.

The XS-1 sensor (PixArt-based, up to 32,000 DPI) is never the reason for a missed shot, and the main buttons use
**optical** switches, which rule out the double-click that eventually hits mechanical switches. It runs on 2.4 GHz
wireless, and the Pulsar Fusion software sets DPI, lift-off distance and polling rate.

| Spec | Detail |
|---|---|
| **Weight** | ~54 g |
| **Shape** | right-handed ergonomic, palm grip |
| **Sensor** | XS-1 (PixArt), 32,000 DPI, 750 IPS |
| **Switches** | optical |
| **Connection** | 2.4 GHz wireless, wired |
