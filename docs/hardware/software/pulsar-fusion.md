# Pulsar Fusion Drive

Pulsar's software sets up my [Xlite V4 mouse](/hardware/accessories/mouse): DPI stages, lift-off distance, polling rate,
button mapping and firmware. Settings are stored in the mouse, so I only open it to change them.
