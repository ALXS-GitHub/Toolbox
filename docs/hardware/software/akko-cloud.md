# Akko Cloud Driver

Akko's software sets up my [magnetic-switch keyboard](/hardware/accessories/keyboard): each key's actuation point, Rapid
Trigger, multi-action keys (DKS), key remapping, lighting and firmware. As with the mouse, everything is stored in the
keyboard.
