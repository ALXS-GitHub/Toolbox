# AMD Software: Adrenalin Edition

AMD's software installs the drivers for the [RX 9070 XT](/hardware/computer) and handles everything related to the
graphics card: per-game profiles, FreeSync to sync frames with my [screens](/hardware/monitors), FSR and frame generation
for smoothness, Anti-Lag to cut latency, and an overlay (`Alt+R`) showing in-game performance. It also flags new driver
versions.
